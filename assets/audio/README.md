# 临时原作音频

这些 WAV 是从本机 Righty Tighty XL 的 FSB5 资源解码出的原版样本，按 Unity AudioClip path ID 命名。`music-101.mp3` 是原作音乐样本转码以缩小网页下载。玩法事件映射在 `src/audio.mjs`，详见仓库上一级的 `Righty-Tighty-XL-specials-fx-audio-spec-20261020.md`。

这组声音是当前本机比赛原型的临时素材。后续替换声音时保留事件键与调音参数，逐一替换文件并重新听感校准。

## 原声变调音律

`melodic/` 下的 12 个短 WAV 由 `clip-87.wav`（Bing）和旧版解码的 `clip-94.wav`（Bong）派生。现在默认模式的 `clip-94.wav` 已替换成当前解包目录的原版 `94.wav`，因此 `melodic/manifest.json` 中 clip 94 的旧 SHA-256 只记录制作音律时的来源，不能用来校验当前默认音频。音律是可选扩展；生成脚本 `tools/build_melodic_audio.py` 需要 `ffmpeg` 与 `numpy`，可据当前原版源文件重新生成。短音裁成 0.42 秒并淡出，以便连续转向。

原版背景曲 `music-101.mp3` 的分段频谱分析在全曲多个时段都更接近 G 小调；强节拍脉冲约为 128 BPM。因此转向音符使用 G 小调五声音阶 G、降 B、C、D、F。节拍相位由音频起始后约 25 毫秒估算，网页用十六分音符网格安排短音。五声音阶降低冲突概率，并不保证每个音在每一瞬间都是背景和弦的组成音。普通得分恢复原版 Bong，擦肩得分恢复原版 Bing；冻结只改变游戏速度、音乐滤波与轻微音量，不再实时改变 MP3 播放速度。死亡时音乐淡出。

`guest/` 包含两款隐藏皮肤的六段语音素材、来源提交和转换记录。默认模式的所有球共用原版 Bong 转向音，扩展音律模式才播放这些语音。语音在 G 小调五声音阶内随机选音节、音高与短句；转向走转向音量通道，得分、特殊球、消除和失败走特效音量通道。

`eliminate.wav` 是单独制作的 0.32 秒消除音，不复用原版爆炸样本；由 `tools/generate_eliminate_audio.py` 用 Python 标准库生成。擦肩或炸弹清除敌人时播放，多只敌人同时消除合并为一次提示。设置中的消除试听按钮播放这一文件。转向、特效、背景音乐各有 50%–200%、步进 1% 的独立音量；100% 保持此前混音基准，背景曲原有 `0.4` 音量仍保留。

`tes-theme.mp3` 是用户提供的《突然的陀螺.mp3》的逐字节副本，仅在 TES 球正式局播放；源文件与此副本的 SHA-256 都是 `0D2AE54E9F805B8E4187E92224E068EACE359676F0C7D96C2F2AA9203DC65648`。`character/` 下的 `tes-whip.mp3`、`kobe-man.mp3`、`kobe-mamba-out.mp3`、`kobe-what-can-i-say.mp3` 分别是本次提供的鞭子抽打、Man、Mamba Out、What Can I Say 的逐字节副本。取消的第四段语音份额平均分给三段科比语音。TES 转向声在两种音效模式下播放，默认音量下按短时 RMS 校准为比 TES 背景音乐典型响度高约 10%；用户调整独立音量滑块后以滑块设置为准。科比语音仅在扩展音律模式播放，使用完整原音并对齐现有节奏。没有裁剪、转码或改动其他音频。
