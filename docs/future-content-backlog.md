# 后续内容清单

TES 球和科比球的皮肤、TES 背景音乐以及两球的专属音效已接入。下表的玩法内容已在 v0.2 实现；具体参数记录在 [v0.2 规则记录](v0.2-rule-record.md)。

| 内容 | v0.2 状态 |
| --- | --- |
| 无敌球 | 已实现：5 秒内撞碎敌人，不额外得分；撞墙仍失败。 |
| 虚化球 | 已实现：5 秒内穿过敌人，不触发擦肩；撞墙仍失败。 |
| 45°旋转球 | 已实现为特殊得分点：送达后切换 90°／45°，与左／右转方向独立。 |
| 子弹时间球 | 已实现：5 秒内玩家 150%、敌人及刷怪计时 50%；冻结时敌人仍停止。 |
| 闪现球 | 已实现：每次出现前预警 0.8 秒，出现后有 0.15 秒安全窗口，最多闪现 3 次。 |
| 45°弹球 | 已实现：45°移动，碰上下边界反弹，侧边离场。 |

## 素材约束

已提供 `突然的陀螺.mp3` 作为 TES 球背景音乐、`鞭子抽打.mp3` 作为 TES 转向声，以及 Man、Mamba Out、What Can I Say 三段科比语音。资源按原字节接入；v0.2 没有新增或修改音频素材，新奖励球仅复用现有音效片段。
