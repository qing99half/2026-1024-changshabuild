# 后续内容清单

TES 球和科比球的皮肤、TES 背景音乐以及两球的专属音效已接入。本清单只记录之后的玩法需求，不代表已实现；持续时间、刷新权重和碰撞细节留待对应功能方案确定。

## 特殊小球

| 名称 | 已确定效果 | 实现前待定 |
| --- | --- | --- |
| 无敌球 | 获得后可直接撞碎敌人。 | 持续时间、边界伤害、碎裂得分与视觉反馈。 |
| 虚化球 | 角色半透明，可以穿过敌人。 | 持续时间、边界处理、与其他效果叠加规则。 |
| 45°旋转球 | 使用后转向角度变为 45°。 | 生效时长、再次拾取及恢复 90° 的时机。 |
| 子弹时间球 | 敌人速度变为 50%，角色速度变为 150%。 | 持续时间、生成计时器是否同步减速、与现有冻结/慢动作的叠加规则。 |

## 敌人

| 名称 | 已确定行为 | 实现前待定 |
| --- | --- | --- |
| 闪现球 | 不按常规路径移动；先预警下次出现位置，再闪现。 | 预警时长、闪现频率、出现瞬间的碰撞宽限。 |
| 45°弹球 | 沿 45°方向移动，碰到上、下边界反弹。 | 初始方向、速度、侧边离场及与玩家的擦肩判定。 |

## 素材约束

已提供 `突然的陀螺.mp3` 作为 TES 球背景音乐、`鞭子抽打.mp3` 作为 TES 转向声，以及 Man、Mamba Out、What Can I Say 三段科比语音。资源按原字节接入；不合成、不下载、不修改其他音频素材。
