# Righty Tighty 99 · v0.2 版本记录

## 本版内容

- 每四个刷新槽为一波。奖励球概率随局内分数逐级增长，在 32 分达到固定每五槽一个的上限；高级敌人、高级奖励和特殊得分点同时受分数与波次门槛控制。
- 新增 45°弹球、沿固定水平轨道闪现的敌人，以及无敌、虚化、子弹时间三种奖励球；左转点与 45°点按送达次数和波次逐步开放。
- 新增 `Ctrl+A+B` 效果测试关卡，可直接展示特殊球和九种敌人，测试局不计入存档。
- 子弹时间奖励球改为黑白矢量漩涡。效果期间背景和敌人灰化，角色、得分球和奖励球保持各自颜色；敌人撞边界或被清除时的碎裂粒子改为黑白。

具体门槛、间隔、时长和效果叠加规则见 [v0.2 规则记录](v0.2-rule-record.md)。

## 发布与验证

- 版本标记：`v0.2`
- 在线地址：[GitHub Pages](https://qing99half.github.io/2026-1024-changshabuild/)
