# v0.2.5 规则与试玩参数

状态：代码首版已实现，数值尚需玩家试玩校准。设计依据见 [优化方案](v0.2.5-optimization-plan.md)。

| 系统 | 首版规则或参数 |
| --- | --- |
| 操作 | 单键正常转向；充能满格时，下一次有效转向同帧启动无敌，键盘、鼠标、触屏一致。 |
| 擦肩 | 普通擦肩清敌、充 1 段，不得分、不缩小；极限擦肩清敌、充 2 段、得 1 分。充能最多六段，超过上限的点数直接作废，不结转。原有每三次擦肩风格奖励保留。 |
| 储能 | 六段短弧随角色移动。每次获得充能时，碎裂位置的光团飞向角色，短弧短暂显示累计进度后隐藏；下一次获得充能时再显示。短弧增加深色底边以适配浅色、带光环的皮肤。满格最多储存一次；无敌期间不再充能。 |
| 状态优先级 | 满格转向若处于虚化，则启动无敌并结束虚化；无敌期间储能弧隐藏以免重叠；擦肩充能释放的无敌持续 5 秒。 |
| 道具 | 首次奖励在第 5 刷新槽；低分段后续间隔 8–10 槽，8 分起 7–9，16 分起 6–8，24 分起 5–6，32 分起 4–5。可拾取无敌球已移除，道具刷新槽数不变，其原有抽取份额由当时已开放的其他道具均分。虚化需 7 分及第 5 波，子弹时间需 16 分及第 9 波；子弹时间玩家移速 1.25 倍，敌人和刷新计时仍为 0.5 倍。 |
| 难度 | 菜鸟、入门、困难、噩梦的基础刷怪间隔倍率依次 1.28、1.12、0.96、0.84；局外收益倍率依次 0.8、1.0、1.35、1.7。默认入门。 |
| 长期扶持 | 最近最多 8 局的送达次数和存活时间参与下一局修正；至少 2 局后开始。四档修正上限依次 ±12%、±9%、±6%、±3%，局内不突变。 |
| 夹击缓解 | 普通敌人生成时对玩家附近的近期重压、现存接近敌人及候选重复高度进行最多约 5 次重抽；不会消除所有双敌局面。 |
| 结算 | 局外收益暂按 `floor((原始局内分 + 皮肤修正后的风格点) × 档位收益倍率)`；倍率不进入局内分、敌人解锁或最高分。 |
| 场景 | 已移除送球后从目标圈生长的背景纹样；送球仍按现有规则得分。 |

数值是首版试玩候选，需用真实玩家的送达率、敌人死亡原因、实际道具拾取率、无敌释放率和单位时间局外收益校准。普通擦肩不缩小仅适用于该行为；其他得分来源仍按 v0.2 调整角色体积。

2026-10-30 反馈修订：移除送球后的背景生长纹样；八段充能短弧改为每次获得无敌充能时短暂展示累计进度，随后隐藏，充能与释放规则保持不变。

2026-11-01 反馈修订：移除可拾取无敌球、子弹时间移速加成减半、充能由八段改为六段且溢出作废，并增强各皮肤充能显示对比。上条为历史记录，以本条及上表为当前规则。
