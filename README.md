# Righty Tighty XL 网页玩法原型

面向手机横屏浏览器和桌面浏览器的单键街机游戏。玩法参考本机安装的《Righty Tighty XL》。界面保留双区首页、皮肤兑换卡片和结算卡片；已接入原版 Logo、图标、目标圈、七种敌人及道具素材，并重建背景分数、预警、尾迹和命中粒子。音频沿用此前接入的本机游戏音频。

## 运行

需要 Node.js 20 或更新版本，无需安装依赖。

```powershell
cd 'D:\10.23 1024bulid\righty-web-game'
npm run dev
```

桌面打开 `http://127.0.0.1:4173`。手机与电脑连同一个局域网，横屏打开 `http://电脑局域网IP:4173`。

## 操作和规则

- 空格、鼠标点击或触屏点击：转向 90°；Esc 或左上角按钮暂停。
- 首次开始进入三段教程：按键转向、拾取并送回光点、避开敌人。完成后直接开始正式游戏。菜单里的“练习操作”可以重玩，也可以随时跳过。教程不增加纪录或皮肤点数。
- 拾取光点后送回白色圆环得 1 分。特殊光点送达后反转转向，并短暂慢动作。
- 在敌人运动轨迹前方垂直穿过，或在敌人上、下侧与之相向移动，进入擦肩范围并安全离开可得 1 分；不要求转弯。同向或姿态不符不会消除。擦肩安全判定带较上一版缩小 25%，致死碰撞范围不变。近距离擦肩另给风格点，连续三次擦肩再给风格点。风格点只计入结算兑换收益，不提高局内敌人解锁速度。额外道具有加 2 分、冻结和炸弹三种。炸弹扩张环扫过敌人时，每只敌人独立爆裂。
- 七种敌人按比赛版分数门槛 0、2、4、6、8、10、12 逐渐加入；新种类首次出现会优先出场。横条、竖条、伸缩六边形、渐隐方块、红色小球和上下双体各有不同碰撞或动画，撞墙后按各自主色碎裂。
- 角色会逐渐变大；得分后缩小，速度和成长速度增加。撞障碍或越界后结算。
- 本局分数和风格奖励在结算时加入可用点数，生涯累计点数不随购买减少。首页可购买并装备 10 款常规皮肤；每款有专属转向音色和粒子。皮肤越贵，危险圈越小，拾取与擦肩安全带越宽；移动速度仅有 1% 的手感差异。
- 两款隐藏球在生涯累计 150／250 分时揭示，再分别花 300／450 可用点数购买。哈吉米和大狗叫使用各自的三音节语音，按本游戏音高表重新变调，送达时会奏出完整三音节。
- 已揭示但未购买的皮肤可以试听和预览；购买点数不足时会显示差额。此时开始一局会明确使用已拥有的经典红。教程统一使用经典红参数。
- 菜单可将动态效果切换为“减弱”，减少粒子和震屏，但保留颜色及声音提示。
- 菜单可切换常规球的“原声音律／原版”转向音效。原声音律从原版 Bing/Bong 音效制作 12 个定音短音，按角色所在的上中下区域和转向后的朝向选择，使用原版背景音乐及 G 小调五声音阶。两款隐藏球始终使用自身语音音色。
- 所有触发音效统一增益为此前的 150%，经过压缩器防止峰值削波；背景曲的文件和音量设置保持原样。

## 对照与特效检查

- `http://127.0.0.1:4173/?debug=1` 在画面底部显示测试按钮，可直接触发加 2 分、冻结、炸弹、反转点、七种敌人展示和撞墙碎裂；测试页使用独立存档。
- `http://127.0.0.1:4173/?mode=original` 使用原版敌人解锁分数 0、5、10、15、20、25、30；默认网址使用比赛版门槛。两个参数可以合用。

`npm test` 运行核心规则测试。改版原因、参数与验收记录见 [回滚与重做方案](../Righty-Tighty-XL-rollback-redesign-plan-20261020.md)。导出资源及来源记录在 `assets/original/manifest.json`；当前素材用于本机复现，公开发布前应确认使用许可或替换。

修改后的音律 WAV 与来源和音高复测记录见 `assets/audio/melodic/manifest.json`，可通过 `tools/build_melodic_audio.py` 从保留的原版音效重新生成。
