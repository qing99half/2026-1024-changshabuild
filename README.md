# Righty Tighty 99 网页游戏 v0.2

在线游玩：[GitHub Pages 静态版](https://qing99half.github.io/2026-1024-changshabuild/)（随 `main` 分支自动更新）。

面向手机横屏浏览器和桌面浏览器的单键街机游戏。玩法参考本机安装的《Righty Tighty XL》。界面保留双区首页、皮肤兑换卡片和结算卡片；标题以原版 Logo 为底稿，将 XL 改为 99。原版七种敌人与旧道具沿用导出资源，新增两种敌人及三种奖励球用 Canvas 绘制。音频沿用此前接入的本机游戏音频。

## 运行

需要 Node.js 20 或更新版本，无需安装依赖。

```powershell
cd 'D:\10.23 长沙造物\2026 1024 waytoagi\10.23 1024bulid\righty-web-game'
npm run dev
```

桌面打开 `http://127.0.0.1:4173`。手机与电脑连同一个局域网，打开 `http://电脑局域网IP:4173`。手机打开时会尝试切换横屏；浏览器要求用户操作时，点“开启横屏”进入全屏并锁定方向。若浏览器不支持方向锁定，请打开系统自动旋转并横过手机。横屏界面会占满可用屏幕，触屏点击画面即可转向；安装到主屏幕后，应用清单也请求横屏启动。

## 操作和规则

- 空格、鼠标点击或触屏点击：转向 90°，获得 45°点后切换为 45°；Esc 或左上角按钮暂停。
- 首次开始进入三段教程：按键转向、拾取并送回光点、避开敌人。完成后直接开始正式游戏。菜单里的“练习操作”可以重玩，也可以随时跳过。教程不增加纪录或皮肤点数。
- 拾取光点后它紧贴玩家，粒子仍沿移动路径留下拖尾；送回白色圆环得 1 分。反转点和 45°点都要送达才切换模式，并触发同款轻量提示和短暂慢动作。反转点独立切换左／右转；45°点独立切换 45°／90°。普通模式的首个反转点需累计 12 次普通送达且达到第 6 波，首个 45°点需反转点已送达、累计 20 次普通送达且达到第 10 波。此后特殊点间隔随分数由 5–7 缩至 3–5 个点位。
- 在敌人运动轨迹前方垂直穿过，或在敌人侧面与之相向移动，进入擦肩范围并安全离开可得 1 分；不要求转弯。同向或姿态不符不会消除。擦肩安全判定带较上一版缩小 25%，致死碰撞范围不变。近距离擦肩另给风格点，连续三次擦肩再给风格点。风格点只计入结算兑换收益，不提高局内敌人解锁速度。额外道具有加 2 分、冻结、炸弹、无敌、虚化和子弹时间六种。后三者按分数与波次双门槛开放，效果持续 5 秒；冻结优先于子弹时间的敌人减速。无敌持续时有暖金色背景蒙版与双层角色光环；虚化持续时有冷青色蒙版、半透明角色和错位残像。子弹时间奖励球使用旋转的黑白 SVG 漩涡；拾取后背景与敌人灰化、敌人碎裂粒子变黑白，主角、得分球和其他奖励球保持原色。炸弹扩张环扫过敌人时，每只敌人独立爆裂。
- 九种敌人逐渐加入；新种类首次出现会优先出场。普通模式每 4 个刷新槽为一波，奖励槽也计入；九种敌人须同时达到分数 0、3、6、9、12、15、18、22、28 和波次 1、3、5、7、9、11、13、15、18 才解锁。45°弹球碰到上下边界反弹；闪现球沿生成时确定的水平轨道从一侧到另一侧依次闪现三次，每次先预警目标位置，出现后留 0.15 秒安全窗口。两种新敌人均为纯色正方形，画面尺寸和方形碰撞框都比上一版缩小 20%。白色双方块是同时生成、各自移动和判定的两个单位；普通敌人身后呈现半透明残影，隐身和闪现敌人没有运动残影。
- 角色会逐渐变大；得分后缩小，速度和成长速度增加。擦肩或炸弹清除的敌人碎成对应颜色的下落粒子；撞障碍或越界时玩家与场上所有敌人各自碎裂，约 2 秒后结算。
- 本局分数和风格奖励在结算时加入可用点数，生涯累计点数不随购买减少。首页可购买并装备 10 款常规皮肤；默认转向音效统一使用原版 Bong，每款保留各自的视觉粒子。皮肤越贵，危险圈越小，拾取与擦肩安全带越宽；移动速度仅有 1% 的手感差异。
- 两款隐藏球在生涯累计 150／250 分时揭示，再分别花 300／450 可用点数购买。默认模式中它们也使用原版转向音效；扩展音律模式才会启用各自的三音节语音。
- TES 球和科比球追加在旧皮肤之后。TES 球生涯累计 350 分揭示、花 600 点购买：移动 +1%、危险圈 −10%、拾取 +10%、擦肩带 +10%、风格收益 +18%。科比球生涯累计 500 分揭示、花 750 点购买：移动 −1%、危险圈 −12%、拾取 +8%、擦肩带 +12%、风格收益 +24%。上一版已免费获得两球的旧存档会保留所有权，且不会因此虚增累计分。TES 球是红色圆球，中央为参考图中的白色断开 T；局内图案以 120°/秒自转，每次有效转向使转速增加 20%，额外转速每秒衰减 1% 至基准，暂停时停止，重开时重置；移动和碰撞不受影响。正式局播放用户提供且未转码的 `tes-theme.mp3`，转向播放提供的鞭子声。科比球为黑棕圆球、黄紫球衣和紫色 24 号，继续播放原背景曲；扩展音律模式中的转向、拾取、得分、特殊球、消除和失败随机播放 Man、Mamba Out、What Can I Say 三段完整语音，各占约三分之一。四段新音频均未转码或改动。
- TES 球每次转向时，从球外固定的握柄甩出短暂的红白鞭影；鞭梢沿正弦曲线抽到移动中的球表面，在接触点甩出 4–6 颗定向粒子，然后回收淡出。携带小球时覆盖层改为半透明，仍能看见 T 旋转；球边缘持续掉落少量红白粒子，频率随转速从每秒约 2 颗上升，最多每秒 12 颗。“动态效果：减弱”会降低粒子数量。
- 已揭示但未购买的皮肤可以试听和预览；购买点数不足时会显示差额。此时开始一局会明确使用已拥有的经典红。教程统一使用经典红参数。
- 首页或暂停界面可进入设置。动态效果可切换为“减弱”，减少常规粒子和震屏；失败碎裂仍保留每个角色 75 粒、每个敌人 50 粒的颜色提示。
- 键盘依次按 Shift+Tab、P 可领取 2000 开发者点数；每重新输入一组快捷键都可再次领取，点数和生涯累计分会保存。
- 设置中的“音效模式”默认原版：所有球的转向使用解包的原版 clip 94，音高随机 `.8–.85`、单次增益 `.4`、三个播放声道轮替。扩展音律模式使用从 Bing/Bong 制作的 12 个定音短音；哈基米、大狗叫在转向、拾取、得分、特殊球、消除及失败时随机组合语音音节，音高限定在 G 小调五声音阶。原版模式不触发隐藏球语音。
- 设置中的转向、特效、背景音乐音量各有独立滑块，范围 50%–200%，步进 1%，默认 100%，改动即时生效并保存。特效音量涵盖得分、特殊球和消除；消除使用独立 WAV，可在设置中试听。100% 时沿用原有混音，背景曲音量基准仍为 `.4`。

## 对照与特效检查

- 普通模式首次奖励球仍在第 7 个刷新槽；此后刷新间隔随分数由 14–18 槽逐级缩至 32 分时固定 5 槽。无敌、虚化、子弹时间球分别需要 10 分／第 6 波、18 分／第 10 波、26 分／第 14 波。敌人刷新时间由 `max(0.8, 2 - 分数/60)` 控制。
- `Ctrl+A+B` 开关效果测试关卡。面板可直接触发六种奖励球与两个特殊得分点、生成九种敌人，并提供清除与重置；测试局不自动刷新或结算进度。
- `http://127.0.0.1:4173/?mode=original` 保留旧敌人、奖励、特殊点和刷新时间曲线，用于对照。

`npm test` 运行核心规则测试。改版原因、参数与验收记录见 [回滚与重做方案](../Righty-Tighty-XL-rollback-redesign-plan-20261020.md)。导出资源及来源记录在 `assets/original/manifest.json`；当前素材用于本机复现，公开发布前应确认使用许可或替换。

## Windows 便携版

运行 `npm run package:win`，生成 `release/Righty-Tighty-99-v0.2-win-x64.exe`。该文件为无需安装的单文件 Windows x64 版本，双击启动独立游戏窗口；本地存档保存在用户的应用数据目录。运行 `npm run desktop` 可在打包前检查桌面版。

修改后的音律 WAV 与来源和音高复测记录见 `assets/audio/melodic/manifest.json`，可通过 `tools/build_melodic_audio.py` 从保留的原版音效重新生成。

七类声画特效的原版对象、脚本和参数见 [原版代码复现记录](../game-analysis-reports/Righty-Tighty-XL-original-parity-plan-v2-20261024.md)。背景得分环取自 `BackgroundPointExplode` GO265 / PS760，分数同帧更新。后续按反馈将主拖尾改为稀疏的半透明残影、特殊球提示改为普通点同款轻量效果、携带球贴紧玩家；白色双方块按两个独立单位处理。
